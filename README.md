# FlexComfort Landing Page

## GitHub upload structure

flexcomfort-landing/
├── index.html
└── assets/
    └── product.jpg

## Image filename

Aapki jo original FlexComfort product image hai usko:
assets/product.jpg

naam se upload karna hai.

### Optional future images
Agar baad me extra visuals add karne ho to ye filenames use kar sakte ho:
- assets/hero-joint.jpg
- assets/how-to-use.jpg
- assets/review-1.jpg
- assets/review-2.jpg
- assets/review-3.jpg

Current code ko chalane ke liye sirf `product.jpg` required hai.

## GitHub Pages
1. GitHub par new repository banao.
2. `index.html` root me upload karo.
3. `assets` folder banao aur `product.jpg` usme upload karo.
4. Settings → Pages → Deploy from branch → main / root select karo.
5. Save ke baad GitHub Pages URL open karo.
